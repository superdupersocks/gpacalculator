# /gpa-scale/ chart images (drafts, not on the site yet)

One per page, rendered by `scripts/render_gpa_scale_images.py` at the exact pixel size of the live file it
replaces, with the same file name (`3.8-GPA.png` replaces `wp-content/uploads/3.8-GPA.png`, attachment 28473).
WordPress then regenerates the sized copies (`3.8-GPA-870x1024.png` …) under their existing names.
`alt.json` holds the new alt text per page.
